# RtfNumberMultiply 更新日志

## [v2.1.2] - 2026-07-31
- **提示更新**：底部提示改为「WPS 选中数字 → 回到此处按 空格」
- **窗口高度缩小**：移除按钮后从 480 缩减至 430

## [v2.1.2] - 2026-07-31

### Bug 修复
- 移除诊断用 MessageBox 代码，恢复静默处理
- 修复删除按钮 Text 从空字符串改回 `✕`（v2.1.1 整理时遗漏）

## [v2.1.1] - 2026-07-31

### Bug 修复
- 移除 `Clipboard.Clear()` 调用 — Roslyn v2 沙盒中该方法会触发异常，导致追加工艺被 catch 吞掉，界面无响应。用 `Clipboard.SetText("")` 替代清空操作。

## [v2.1.0] - 2026-07-31

### 改进
- 计算结果固定保留两位小数（`F2`），不再根据输入小数位数动态调整

## [v2.0.0] - 2026-07-28

### 重大变更
- **浮动弹窗常驻**：弹出窗口不再 2s 自动关闭，改为常驻浮动窗口，手动关闭
- **累加模式**：最多 10 个固定槽位，可连续选中数字追加，结果逐条累加
- **交互式「追加」按钮**：点击按钮→弹窗自动隐藏→Ctrl+C 复制选中内容→计算×1.3→弹窗恢复追加
- **自动填空**：新结果填入第一个空槽位，删除后留空，下一轮填入
- **逐条删除**：每条结果旁有 X 删除按钮，可逐条删除
- **顿号分隔 + KN 后缀**：剪贴板格式改为 `130KN、260KN、390KN`
- **实时剪贴板更新**：每追加/删除一条后立即更新剪贴板

## [v1.0.1] - 2026-07-23

### 改进
- 弹窗 2s 后自动关闭

## [v1.0.0] - 2026-07-23

### 新功能
- 选中 RTF 数字后模拟 Ctrl+C 复制
- 正则提取数字（支持整数、小数、负号、千分位逗号）
- 自动 ×1.3 计算
- 结果自动写入剪贴板
- 弹窗显示计算结果
