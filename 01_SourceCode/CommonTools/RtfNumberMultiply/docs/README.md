# RTF数字乘1.3

> Quicker 动作 | CommonTools 系列 | v1.0.0

---

## 功能

在任意 RTF 文档（如 Word、写字板、WPS 等）中选中一个数字后，触发此动作，自动：

1. 模拟 Ctrl+C 复制选中内容
2. 从剪贴板中提取数字
3. 计算 `原始数字 × 1.3`
4. 将结果自动复制到剪贴板
5. 弹窗显示计算结果

## 使用场景

- 工程报价 ×1.3（利润率 30% 加成）
- 成本预估 ×1.3（含税/含管理费）
- 任何需要快速乘以 1.3 的计算

## 使用方法

1. 在 RTF 文档中选中一个数字（如 `100`）
2. 触发此 Quicker 动作
3. 结果自动复制到剪贴板，直接 `Ctrl+V` 粘贴即可

## 支持的数字格式

| 格式 | 示例 | 结果 |
|------|------|------|
| 整数 | `100` | `130` |
| 小数 | `99.5` | `129.35` |
| 带千分位 | `1,234` | `1604.2` |
| 负数 | `-50` | `-65` |

## 技术实现

- **引擎**：Quicker Roslyn v2
- **UI 框架**：Windows Forms（避免后台线程无 Dispatcher 问题）
- **剪贴板操作**：`System.Windows.Forms.Clipboard`
- **键盘模拟**：`user32.dll keybd_event` 模拟 Ctrl+C
