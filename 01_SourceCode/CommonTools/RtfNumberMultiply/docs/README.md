# RTF数字乘1.3

> Quicker 动作 | CommonTools 系列 | v2.2.0

---

## 功能

浮动弹窗常驻交互式 ×1.3 累加器：在 WPS/Word 文档中连续选中数字，按空格键逐条追加计算，最多累加 10 个结果，顿号分隔 + KN 后缀自动复制到剪贴板。

1. 触发动作 → 弹出常驻浮动窗口
2. 在文档中选中一个数字，回到弹窗按**空格键**
3. 自动模拟 Ctrl+C 复制 → 提取数字 → ×1.3 计算（窗口不隐藏）
4. 结果填入第一个空槽位（共 10 个），支持逐条删除
5. 剪贴板实时更新：顿号分隔 + KN 后缀（如 `130.00KN、260.00KN、390.00KN`）
6. 手动关闭窗口

## 使用场景

- 工程报价 ×1.3（利润率 30% 加成）
- 成本预估 ×1.3（含税/含管理费）
- 任何需要在文档中批量乘以 1.3 的计算
- 配合 CAD：结果直接粘贴到 CAD 文本

## 使用方法

1. 触发此 Quicker 动作，弹出浮动窗口
2. 在文档中选中一个数字（如 `100`）
3. 回到弹窗，按**空格键**
4. 重复步骤 2-3，最多累加 10 条
5. 结果已自动复制到剪贴板，直接 `Ctrl+V` 粘贴即可
6. 可点击 ✕ 逐条删除不需要的结果
7. 关闭窗口结束

## 支持的数字格式

| 格式 | 示例 | 结果 |
|------|------|------|
| 整数 | `100` | `130.00KN` |
| 小数 | `99.5` | `129.35KN` |
| 带千分位 | `1,234` | `1604.20KN` |
| 负数 | `-50` | `-65.00KN` |

## 技术实现

- **引擎**：Quicker Roslyn v2
- **UI 框架**：Windows Forms（避免 WPF 无 Dispatcher 问题）
- **剪贴板操作**：`System.Windows.Forms.Clipboard`
- **键盘模拟**：`user32.dll keybd_event` 模拟 Ctrl+C
- **槽位管理**：10 个固定槽位，自动填空，逐条删除
- **触发方式**：Form.KeyPreview + KeyDown 事件监听空格键
