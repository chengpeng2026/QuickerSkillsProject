# FileExactCopy — 文件精准复制

## 概述

从预设的源文件夹中，按**精确文件名**匹配文件，多选确认后**复制**到通过弹窗选择的目标文件夹。

## 适用场景

- 从固定的模板库文件夹中，挑选指定的文档模板复制到当前项目文件夹
- 从固定的资源文件夹中，将指定图片/字体等素材复制到工作目录
- 任何需要"从固定源按精确文件名取文件→放到指定目标"的场景

## 使用方式

**运行动作：**
1. 动作读取预设的「源文件夹」和「文件名」
2. 在源文件夹中查找匹配的文件
3. 弹出多选窗口，勾选要复制的文件 → 确定
4. 弹出文件夹选择器，选择目标文件夹 → 确定
5. 逐个复制（遇同名弹窗确认覆盖/跳过）
6. 右下角 Toast 通知复制结果

**配置：**
- 右键动作 → **设置**，填入源文件夹路径和文件名（多个用 `;` 分隔）

## 特点

| 特性 | 说明 |
|------|------|
| 精确匹配 | 按文件名精确匹配，不会复制意外文件 |
| 多文件支持 | 分号 `;` 分隔多个文件名，一次性查找 |
| 多选确认 | 匹配到多个文件时，弹窗勾选确认后再执行 |
| 同名处理 | 目标已有同名文件时，逐文件弹窗询问覆盖/跳过 |
| 自动建目录 | 目标文件夹不存在时自动创建 |
| Toast 通知 | 完成/失败时右下角悬浮通知，不打断工作流 |
| 记忆配置 | 源文件夹和文件名会记忆上次设置 |
