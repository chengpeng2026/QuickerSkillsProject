# 简单弹窗

- **版本**: v1.0.0
- **状态**: stable
- **ActionId**: `2f125c4f-9e40-440a-b221-f8bff969993e`
- **分类**: 通用工具

## 功能说明

一个简单的 WPF 弹窗提示动作，支持自定义弹窗文本和标题。

## 版本历史

| 版本 | 日期 | 变更 |
|------|------|------|
| v1.0.0 | 2025-07-10 | 初始化版本 |

## 输入变量

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `popup_text` | 文本 | `你好，来自 Quicker！` | 弹窗显示的文本内容 |
| `popup_title` | 文本 | `提示` | 弹窗标题 |

## 使用说明

1. 触发本动作
2. 弹出包含自定义文本和标题的 MessageBox
3. 点击确定关闭
