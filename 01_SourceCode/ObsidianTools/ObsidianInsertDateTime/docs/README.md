# Obsidian 插入当前日期时间

- **版本**: v1.1.0
- **状态**: stable
- **ActionId**: `15889368-900e-456a-95da-8c5e9e1f34bf`
- **分类**: Obsidian 笔记效率工具

## 功能说明

在 Obsidian 笔记编辑状态下，自动在光标处插入当前日期时间（`yyyy-MM-dd 星期X HH:mm` 格式）。选中文本时自动替换选中内容。

## 版本历史

| 版本 | 日期 | 变更 |
|------|------|------|
| v1.1.0 | 2025-07-12 | 修复双换行问题：粘贴文本不带换行符，单独模拟 Enter 控制光标跳到下一行 |
| v1.0.0 | 2025-03-22 | 初始版本：Obsidian 窗口校验、光标处插入格式化日期时间、选中文本替换、气泡提示 |

## 技术实现

- **引擎**: Quicker Roslyn v2（零样板模式）
- **输入方式**: 剪贴板粘贴（Clipboard + Ctrl+V），支持光标插入与选中替换
- **窗口校验**: `GetForegroundWindow` → 进程名包含 `obsidian`
- **日期格式**: `DateTime.Now` + `zh-CN` CultureInfo 生成中文星期名
- **提示方式**: 动态反射定位 Quicker Toast Notifier（兼容各版本混淆名）

## 使用说明

1. 在 Obsidian 笔记中进入编辑状态
2. 触发本 Quicker 动作（快捷键/面板点击）
3. 日期时间自动插入到当前光标位置
4. 自动换行，光标跳到下一行
