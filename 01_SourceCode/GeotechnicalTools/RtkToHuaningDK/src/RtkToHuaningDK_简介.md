# RTK测点数据导入华宁DK文件

## 功能概述
读取RTK设备导出的DAT格式测点数据（字段顺序：点号、X坐标、Y坐标、高程），自动完成数据清洗、格式转换与坐标顺序适配后，按照华宁岩土勘察软件DK文件的标准格式，追加写入到用户指定的目标DK文件中。

## 适用场景
- 岩土工程勘察外业数据内业整理
- RTK测量数据批量导入华宁软件
- 测绘数据跨平台格式转换

## 核心特性
- 🗺️ **双模式触发**：资源管理器选中DAT文件右键导入，或手动选择文件
- 🔒 **文件安全**：写入前自动备份原DK文件，仅末尾追加不修改已有数据
- 🧹 **智能解析**：自动识别逗号/空格/制表符分隔，跳过表头及注释行
- 🔄 **坐标适配**：自动完成 X/Y 坐标顺序互换（DAT → 华宁DK标准）
- 📊 **进度可视化**：批量处理时显示实时进度和当前处理行号
- ⚠️ **异常兜底**：写入失败自动还原备份，无效行逐条统计并报告
- 🌐 **编码兼容**：支持全角/半角符号混合的DAT文件，自动统一转换
- 📏 **精度保留**：坐标保留3位小数，高程保留2位小数

## 使用方法
1. **方式一**：在资源管理器中选中 `.dat` 测点文件 → 右键 → 选择「导入到华宁DK文件」
2. **方式二**：直接运行动作 → 依次选择源DAT文件和目标DK文件
3. 等待自动解析、转换和写入，完成后自动打开目标文件所在目录
