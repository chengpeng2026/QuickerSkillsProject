# Quicker 动作搭建分步教程：微信URL一键用Edge打开

## 概览

本动作实现：在微信PC版内置浏览器中，一键提取当前页面URL，并使用Microsoft Edge打开。

**特别说明**：本方案采用纯 PowerShell 代码实现，不使用 Quicker 可视化键鼠模块（稳定性更高、跨版本兼容更好）。

---

## 第一步：创建新动作

1. 打开 Quicker 面板 → 点击 `+` 新建动作
2. 选择 **空白动作**（或直接右键空白按钮位 → 新建动作）
3. 动作名称：`微信→Edge打开`
4. 图标建议：`fa:Solid_ExternalLinkAlt:#2F80ED`（或自行选择）

---

## 第二步：添加模块 —【运行PowerShell脚本】

在动作编辑器左侧模块列表中：

1. 搜索栏输入 `PowerShell` → 拖入 **【运行PowerShell脚本】** 模块
2. 也可以展开 `系统` 分类 → 直接拖入

⚠️ **关键：本动作只使用一个模块，不需要任何键鼠模块。**

---

## 第三步：粘贴脚本代码

### 3.1 基础版 vs 增强版

| 特性 | 基础版 | 增强版 |
|------|--------|--------|
| 窗口检测 | 进程主窗口 | 全局窗口枚举 |
| 输入法保护 | Escape | Escape + 切换英文键盘 |
| 重试机制 | 3次剪贴板重试 | 3次全流程重试 |
| Edge无痕模式 | ❌ | ✅ 可开关 |
| 详细日志 | 基础 | 十六进制字符dump |
| 多微信兼容 | ✅ | ✅ (更全面) |
| 代码行数 | ~190行 | ~410行 |

**建议：初始使用基础版 → 有问题再换增强版（日志更详细便于排查）。**

### 3.2 粘贴代码

1. 双击模块打开编辑窗口
2. 将 `WeChatUrlToEdge.ps1`（基础版）或 `WeChatUrlToEdge_Enhanced.ps1`（增强版）**全部内容**复制
3. 粘贴到脚本输入框

---

## 第四步：模块配置参数（关键！）

### 4.1 必需配置项 ⚠️

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **脚本来源** | `输入脚本内容` | 直接粘贴，不用文件路径 |
| **运行超时(秒)** | `15` | 足够完成整个流程 |
| **运行目录** | 留空（默认） | |
| **运行窗口样式** | `隐藏` | ⚠️ 必须隐藏，禁止弹出黑框 |
| **以管理员身份运行** | `否` | 不需要 |
| **错误时继续运行** | `是` | 即使报错也继续，确保剪贴板不丢失 |

### 4.2 共享变量

| 变量名 | 方向 | 说明 |
|--------|------|------|
| `result` | 输出 | 脚本返回的执行结果字符串 |

### 4.3 PowerShell 执行策略

Quicker 的 PowerShell 模块使用 `-ExecutionPolicy Bypass` 执行，无需额外设置。

### 4.4 STA 模式确认

PowerShell 模块默认以 STA 模式运行（支持 `System.Windows.Forms.Clipboard`），**无需额外设置**。

---

## 第五步：动作变量定义

在动作编辑器右侧 → **变量定义** 标签页，添加：

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `result` | 文本 | （空） | 脚本执行结果 |

> 如果使用增强版 + 无痕模式开关：可添加 `incognito` 变量（Bool类型，默认 false）。

---

## 第六步：快捷键/触发方式绑定

### 推荐触发方式

| 方式 | 设置 | 适用场景 |
|------|------|----------|
| **鼠标手势** | 在微信浏览器中右键下滑 | 最方便、最推荐 |
| **键盘快捷键** | `Ctrl+Shift+E`（不与微信冲突） | 键盘党首选 |
| **轮盘菜单** | 添加到微信进程轮盘 | 多动作整合 |

### 触发条件（进程匹配）— 可选但推荐

在动作触发条件设置中：

- **进程名匹配**：`WeChat.exe` / `Weixin.exe` / `WXWork.exe`
- 这样动作只在微信窗口激活时才可见/可用
- 避免在其他应用中误触发

---

## 第七步：延时可调参数说明

打开脚本文件，找到顶部 `[可调参数]` 区域，根据电脑性能调整：

```powershell
# 高性能电脑 (SSD + 16G内存+)
$DELAY_BEFORE_CTRL_L  = 100   # 可降低
$DELAY_BETWEEN_KEYS   = 50    # 可降低
$DELAY_BEFORE_CLIP    = 100   # 可降低

# 低性能电脑 / 远程桌面
$DELAY_BEFORE_CTRL_L  = 400   # 加大
$DELAY_BETWEEN_KEYS   = 200   # 加大
$DELAY_BEFORE_CLIP    = 400   # 加大
```

## 第八步：测试验证

1. 打开微信 → 点开任意公众号文章或聊天链接
2. 等到页面完全加载（看到网页内容）
3. 触发动作（快捷键/鼠标手势）
4. 预期结果：Edge 自动打开该网页
5. URL 同时保留在系统剪贴板中

---

## 第九步：故障快速排查

| 现象 | 最可能原因 | 解决 |
|------|-----------|------|
| 无反应 | 微信浏览器窗口未识别 | 确保页面在前台 |
| Edge打开但URL空白 | 地址栏未被选中 | 加大 `DELAY_BETWEEN_KEYS` |
| 剪贴板为空 | 输入法吃掉了 Ctrl+C | 开启 `$ESCAPE_BEFORE_ACTION` |
| 弹窗"未获取有效链接" | 页面是本地文件(file://) | 正常，非HTTP不打开 |
| Edge找不到 | 非标准安装路径 | 在脚本中手动添加路径 |

详细故障排查见 `WeChatUrlToEdge_故障排查.md`。

---

## 第十步：企业微信/多开兼容

脚本已内置 `WXWork`（企业微信）进程名匹配，无需额外配置。

微信多开场景：脚本只获取**第一个**匹配窗口的URL。如需指定特定微信实例，可在脚本中修改 `$WECHAT_PROCESS_NAMES` 过滤逻辑。
